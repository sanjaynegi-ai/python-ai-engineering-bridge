# Policy: Access Requests

## Accounts and system access

Employees request access to systems through the access portal. Each request needs approval from the employee's manager and from the system's owning team. Access is granted for the role, not the person: when someone changes role, their old access is removed.

## Badges

Building badges are issued by it-support. A lost badge must be reported within 24 hours so that it can be disabled. Temporary badges are valid for one day. If the badge readers at a site stop working, site security lets people in by hand and logs every entry; it-support treats a site-wide badge reader failure as a P2.

## Reviews

Every quarter, each team reviews who has access to its systems, and removes access that is no longer needed. The review is recorded in the access portal.
