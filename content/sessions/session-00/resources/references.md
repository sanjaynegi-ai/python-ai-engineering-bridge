# Session 00: References

Primary sources are preferred. These interfaces change; verify model IDs and installation commands before production use.

## Foundations

- [Attention Is All You Need](https://arxiv.org/abs/1706.03762) — the Transformer architecture.
- [The Illustrated Transformer](https://jalammar.github.io/illustrated-transformer/) — a visual companion to the paper.
- [Hugging Face tokenizers](https://huggingface.co/docs/transformers/main/tokenizer_summary) — subword tokenisation and model vocabularies.

## Model access

- [OpenAI text generation](https://developers.openai.com/api/docs/guides/text) — current Responses API examples.
- [OpenRouter API quickstart](https://openrouter.ai/docs/quickstart) — OpenAI-compatible gateway calls.
- [OpenRouter free models](https://openrouter.ai/models?max_price=0) — current free-model availability; it can change.
- [Ollama API](https://docs.ollama.com/api/introduction) — local HTTP API.
- [Hugging Face text generation](https://huggingface.co/docs/transformers/main/en/main_classes/text_generation) — local `generate` usage.
- [LangChain model integrations](https://docs.langchain.com/oss/python/integrations/chat/) — common chat-model interface.

## Retrieval and agents

- [scikit-learn cosine similarity](https://scikit-learn.org/stable/modules/generated/sklearn.metrics.pairwise.cosine_similarity.html) — definition and practical API.
- [LangChain retrieval](https://docs.langchain.com/oss/python/langchain/retrieval) — retrieval building blocks and RAG patterns.
- [LangGraph overview](https://docs.langchain.com/oss/python/langgraph/overview) — stateful workflows and agent infrastructure.
- [OWASP LLM risks](https://genai.owasp.org/) — security risks and mitigations for LLM applications.
