# Python to AI Engineering Bridge

**A practical Python bridge for experienced software engineers moving into AI engineering.**

This repository supports a focused learning journey from professional software development in Java, C#, JavaScript/TypeScript, or similar languages to building production-minded Python applications for AI.

The course does not re-teach programming fundamentals. It concentrates on how Python expresses familiar engineering ideas, the conventions and pitfalls that matter in real projects, and the skills required before progressing into advanced AI engineering.

## Course intent

The goal is to help experienced developers become independently productive in Python—not simply follow generated examples.

By completing the course, learners should be able to:

- Read, write, debug, and test maintainable Python applications.
- Create reproducible projects and manage dependencies with `uv`.
- Work with files, JSON, HTTP APIs, validation, and asynchronous I/O.
- Build services with Pydantic and FastAPI.
- Integrate LLM APIs directly and evaluate when frameworks add value.
- Use selected LangChain and LangGraph abstractions with clear engineering judgment.
- Build and explain a small retrieval-augmented generation (RAG) application.
- Use AI coding assistants responsibly while retaining ownership of the design and code.

## Who this course is for

This course is designed for software professionals with several years of engineering experience who are new to Python or have only used it occasionally.

It is especially relevant to:

- Backend, frontend, and full-stack engineers.
- Java and Spring Boot developers.
- C# and .NET developers.
- JavaScript, TypeScript, and Node.js developers.
- QA, Selenium, and automation engineers.
- Technical leads and architects preparing for AI-focused work.

Learners are expected to understand programming concepts such as functions, classes, collections, exceptions, APIs, JSON, debugging, and Git. The course focuses on transferring that experience into idiomatic Python and preparing for roles such as **AI Engineer**, **Forward Deployed Engineer**, and **GenAI Architect**.

## How the learning journey works

The course runs across **8 weekends**, with **16 live sessions** of approximately two hours each. Learners should also plan for 3–5 hours of independent practice between weekends.

Each session combines:

1. **Concept notebooks** — conversational explanations, visual mental models, working code, production considerations, and guided experimentation.
2. **Practice quizzes** — predict-the-output questions, debugging exercises, code completion, and engineering judgment checks with expandable answers.
3. **Workbook assignments** — realistic implementation work completed in actual Python projects rather than only inside notebooks.
4. **Progressive projects** — four applications that develop from structured data processing to APIs, LLM integration, and a RAG capstone.
5. **Assessments** — an entry diagnostic, project milestones, a capstone rubric, and a final Python-readiness assessment.

The learning progression is:

> **Understand → Experiment → Implement → Debug → Test → Explain → Extend**

Early sessions provide detailed guidance. Later sessions shift toward requirements, acceptance criteria, architectural decisions, and independent implementation.
